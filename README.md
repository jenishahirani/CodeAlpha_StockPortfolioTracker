
# Stock Portfolio Tracker

## About the Project
The Stock Portfolio Tracker is a simple Python project developed as part of the CodeAlpha Python Programming Internship. It calculates the total investment value based on predefined stock prices and the quantity entered by the user.

## Features
- Stores stock prices using a Python dictionary.
- Accepts stock symbols from the user.
- Automatically converts stock names to uppercase.
- Calculates the total investment value.
- Displays an error message for invalid stock symbols.

## Technologies Used
- Python 3
- Dictionary
- User Input and Output
- Conditional Statements
- Basic Arithmetic Operations

## Available Stocks

| Stock Symbol | Price per Share |
|---|---:|
| AAPL | 180 |
| TSLA | 250 |
| GOOGL | 150 |
| MSFT | 420 |
| AMZN | 190 |

*Note: These are predefined example prices, not real-time market prices.*

## How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python stock_portfolio_tracker.py
```

5. Enter a stock symbol and the quantity of shares when prompted.
6. View the calculated investment value.
